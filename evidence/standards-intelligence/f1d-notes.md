- تشغيل F1c على PostgreSQL: نجحت كل الفحوص (66 نجاح، 0 فشل) لكن فحص عزل RLS (PGR1) اتخطى بسبب `permission denied to set role` — دور الفحص اتنشأ لكن مستخدم قاعدة البيانات لم يكن مسموحًا له بالتحويل إليه.
- الإصلاح: منح عضوية الدور مع صلاحية SET (`WITH SET TRUE` على PG16+، أو منح عادي على النسخ الأقدم).
- النتيجة الفعلية تُقرأ من `battery-output-f1-pg.txt`؛ لو بقي `SKIP PGR1` فعزل المستأجرين لسه غير مثبت.
