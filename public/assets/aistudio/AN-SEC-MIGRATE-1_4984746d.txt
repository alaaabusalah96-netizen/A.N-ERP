# AN-SEC-MIGRATE-1 — AuthZ guard on A.N migrate write routes (LEAN)
# Priority from audit: migrate POSTs only had AN_MIGRATE_WRITES env gate — not enough.
# Require authenticated session + platform/system admin (KEMIT session interim) before any write migrate.
# Does NOT enable AN_MIGRATE_WRITES. Does NOT change Login. Does NOT migrate data.

## HARD RULES
1. Apply guard to ALL of:
   - POST /api/an/migrate/inventory/warehouses
   - POST /api/an/migrate/inventory/items
   - POST /api/an/migrate/inventory/balances
   - POST /api/an/migrate/accounting/accounts
2. GET dry-run `/api/an/migrate/inventory/dry-run` must also require authentication (same operator class) — no anonymous probing of counts on production.
3. Unauthenticated → 401. Authenticated but not admin → 403.
4. Keep AN_MIGRATE_WRITES check **after** auth (order: auth → then writes flag → then work).
5. Stop at first failure. tsc wait >2 min → once → build → 9–12. One RESULTS REPORT only.

## STEP 3 — Inside `server.ts` (same scope as authenticateSessionOrBearer)

Add helper **after** `authenticateSessionOrBearer` is defined (or immediately before first migrate route if helpers are in outer startServer scope — must see both functions):

```javascript
  async function requireAnMigrateOperator(req: any, res: any): Promise<boolean> {
    const authResult = await authenticateSessionOrBearer(req);
    if (!authResult.authenticated) {
      res.status(authResult.statusCode || 401).json({
        ok: false,
        code: "migrate_unauthorized",
        message: authResult.message || "Unauthorized",
        messageAr: "يلزم تسجيل الدخول لتنفيذ الترحيل",
      });
      return false;
    }
    const user = authResult.user || {};
    const role = String(user.role || "");
    const isAdminRole =
      role === "SystemAdmin" ||
      role === "Admin" ||
      role === "super_admin" ||
      role === "system_admin";
    let platform = false;
    try {
      platform = await isPlatformAdminUser(user.email, user);
    } catch {
      platform = false;
    }
    if (!platform && !isAdminRole) {
      res.status(403).json({
        ok: false,
        code: "migrate_forbidden",
        message: "Forbidden: migrate requires platform or system admin",
        messageAr: "الترحيل متاح لمدير المنصة أو مسؤول النظام فقط",
      });
      return false;
    }
    (req as any).anMigrateUser = user;
    return true;
  }
```
