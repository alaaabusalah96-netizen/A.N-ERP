# AN-ADAPTER-FAIL-CLOSED-1 — No silent primary on company config load failure (LEAN)
# Audit: loadCompanyLikeFromFirestore returns null on any failure → resolve falls back to process primary.
# Distinguish not_found vs error; on error (or fail-closed mode) refuse silent primary.
# Does NOT remove shared-primary when company has no backend fields and doc is truly missing/absent fields.

## HARD RULES
1. `loadCompanyLikeFromFirestore` must NOT swallow errors as null without status.
2. If company document **load throws / permission / unavailable** → callers must get 503/400, **not** primary adapter silently.
3. If company **not_found** and no body backend → primary fallback allowed only with `source: 'process_primary'` and `companyDoc: 'missing'` in resolution metadata.
4. If company **loaded** with `isolation_level=Dedicated` or non-empty `connection_ref` → must use resolveAdapter; never strip to primary on soft failure.
5. Env `AN_ADAPTER_FAIL_CLOSED=1` (default **on** when unset for migrate/inventory A.N routes): treat ambiguous load as fail. Set `AN_ADAPTER_FAIL_CLOSED=0` only for local dev.
6. Stop at first failure. tsc wait >2 min → once → build → 9–12. One RESULTS REPORT only.

### loadCompanyLikeFromFirestore
```typescript
export async function loadCompanyLikeFromFirestore(
  adminDb: any,
  companyId: string
): Promise<CompanyLoadResult> {
  if (!companyId?.trim()) return { status: 'skipped', reason: 'empty_company_id' };
  if (!adminDb) return { status: 'skipped', reason: 'no_admin_db' };
  try {
    const snap = await adminDb.collection('companies').doc(companyId).get();
    if (!snap.exists) return { status: 'not_found' };
    const data = snap.data() || {};
    return {
      status: 'loaded',
      company: {
        id: companyId,
        auth_driver: data.auth_driver,
        db_backend: data.db_backend,
        isolation_level: data.isolation_level,
        connection_ref: data.connection_ref,
      } as CompanyLike,
    };
  } catch (e: any) {
    return {
      status: 'error',
      message: (e?.message || String(e)).slice(0, 200),
    };
  }
}
```
