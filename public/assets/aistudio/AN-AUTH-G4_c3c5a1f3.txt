# AN-AUTH-G4 — Prefer A.N login UI; Firebase only with escape flag (LEAN)
# When AN_ENABLE_AN_LOGIN=1, Login UI defaults to A.N-only unless AN_ALLOW_FIREBASE_LOGIN=1.
# Server Firebase routes stay. No cutoverApproved. Does not delete verify-credentials.

## HARD RULES
1. Server must still serve `/api/auth/verify-credentials`.
2. If `AN_ENABLE_AN_LOGIN` is off → Login behavior stays Firebase-only (pre-G3).
3. If `AN_ENABLE_AN_LOGIN` on and `AN_ALLOW_FIREBASE_LOGIN` off → UI shows **A.N only** (no Firebase toggle).
4. If both on → dual toggle remains (G3 behavior).
5. Stop at first failure. tsc wait >2 min → once → build → 9–12. One RESULTS REPORT only.
