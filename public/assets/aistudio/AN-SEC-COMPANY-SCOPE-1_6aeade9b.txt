# AN-SEC-COMPANY-SCOPE-1 — Company access guard on A.N inventory reads (LEAN)
# Audit: session auth alone does not prove user may access requested companyId.
# Add assertUserCanAccessCompany; enforce on GET inventory warehouses/items/stock.
# Platform/SystemAdmin may access any companyId. Others only matching company_id (and optional company_ids[]).
# Does NOT change adapter fail-closed (next package). Does NOT cut Inventory UI.

## HARD RULES
1. Apply guard **after** authenticateSessionOrBearer succeeds, **before** adapter resolve/list.
2. Missing companyId → 400. Scope fail → 403 with code `company_scope_denied`.
3. Platform owner / SystemAdmin / super_admin → allow any companyId.
4. Else allow if `user.company_id === companyId` OR `companyId` in `user.company_ids` / `user.assigned_company_ids` (if arrays exist).
5. Stop at first failure. tsc wait >2 min → once → build → 9–12. One RESULTS REPORT only.

## STEP 3 — In `server.ts` near other auth helpers (same scope as isPlatformAdminUser)

```javascript
  function userMayAccessCompany(user: any, companyId: string): boolean {
    const cid = String(companyId || "").trim();
    if (!cid || !user) return false;
    const primary = String(user.company_id || user.companyId || user.tenantId || "").trim();
    if (primary && primary === cid) return true;
    const lists = [user.company_ids, user.assigned_company_ids, user.companies]
      .filter(Array.isArray) as any[][];
    for (const list of lists) {
      for (const entry of list) {
        const id = typeof entry === "string" ? entry : entry?.id || entry?.company_id;
        if (id && String(id).trim() === cid) return true;
      }
    }
    return false;
  }

  async function assertUserCanAccessCompany(
    user: any,
    companyId: string
  ): Promise<{ ok: true } | { ok: false; status: number; code: string; message: string; messageAr: string }> {
    const cid = String(companyId || "").trim();
    if (!cid) {
      return {
        ok: false,
        status: 400,
        code: "company_id_required",
        message: "companyId required",
        messageAr: "معرّف الشركة مطلوب",
      };
    }
    let platform = false;
    try {
      platform = await isPlatformAdminUser(user?.email, user);
    } catch {
      platform = false;
    }
    const role = String(user?.role || "");
    const elevated =
      platform ||
      role === "SystemAdmin" ||
      role === "super_admin" ||
      role === "system_admin" ||
      user?.is_platform_owner === true;

    if (elevated) return { ok: true };
    if (userMayAccessCompany(user, cid)) return { ok: true };

    return {
      ok: false,
      status: 403,
      code: "company_scope_denied",
      message: "Forbidden: user cannot access this companyId",
      messageAr: "غير مصرح بالوصول لبيانات هذه الشركة",
    };
  }
```
