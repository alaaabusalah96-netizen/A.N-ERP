# CONSOL-1 — ميزان مراجعة مجمّع للمجموعة

## النطاق
دمج صفوف ميزان المراجعة لأعضاء `CompanyGroup` حسب **كود الحساب** (قراءة فقط).

## API
`GET /api/groups/:id/consol/trial-balance?asOfDate=YYYY-MM-DD` — منصة.

## ملاحظات إلغاء
لا قيود إلغاء تلقائية لقيود بين الشركات في هذه الحزمة؛ تُذكر التحويلات المفتوحة في `eliminationNotes`.
