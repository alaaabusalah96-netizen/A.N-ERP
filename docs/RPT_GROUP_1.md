# RPT-GROUP-1 — ملخص KPI لمجموعة الشركات

## النطاق
تقرير **قراءة فقط** يجمع لكل عضو في `CompanyGroup`:
- عدد الأصناف والمستودعات
- قيمة المخزون (`totalValue`)
- تحويلات بين الشركات المفتوحة (وارد/صادر)
- حالة إقفال دفاتر الكيان

## API
`GET /api/groups/:id/report/summary` — `requirePlatformAdmin`

## حدود
ليس تجميعًا محاسبيًا رسميًا (CONSOL-1 لاحقًا). لا قيود كتابية.
