# INV-INTRANSIT-1 — متابعة التحويلات في الطريق

## المشكلة
مسار التحويل بين المستودعات (إنشاء → إرسال → استلام) موجود، لكن:
- طلبات `fetch` للتحويلات كانت بدون `credentials: 'include'`.
- لا تصفية واضحة لحالة **في الطريق (IN_TRANSIT)** ولا ملخص لأعداد الحالات.

## النطاق (واجهة فقط)
- إضافة `credentials: 'include'` لتحميل بيانات المخزون ولإنشاء/إرسال/استلام التحويل.
- شريط ملخص: بانتظار الإرسال / في الطريق / مكتمل.
- أزرار تصفية: الكل · بانتظار الإرسال · في الطريق · مكتمل.
- شارة التبويب تعرض عدد الشحنات في الطريق عند وجودها.
- لا تغيير لقواعد الخادم أو الحالات أو المحاسبة.
