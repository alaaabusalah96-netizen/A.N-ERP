# A.N ERP — INV-ITEM-CREATE

## المشكلة
كان تبويب الأصناف يعرض الأصناف الموجودة ويتيح فتح بطاقة الصنف، لكنه لا يوفّر مسارًا مباشرًا لإنشاء صنف جديد من نفس التبويب.

## النطاق
- إضافة زر «إنشاء صنف جديد» ونموذج بطاقة صنف داخل تبويب الأصناف.
- إرسال البيانات إلى المسار الموجود `POST /api/inventory/items`؛ لا يتم إنشاء API جديد.
- تضمين `credentials: 'include'` ومفتاح `Idempotency-Key`.
- الحقول الإلزامية في الواجهة: كود الصنف، الاسم العربي، التصنيف.
- الحقول الاختيارية: الاسم الإنجليزي، وحدة القياس، طريقة التقييم المدعومة، حد إعادة الطلب، تتبع الدُفعات، وتتبع الرقم المسلسل.
- إنشاء بطاقة الصنف لا يضيف كمية إلى الرصيد؛ الكميات تسجّل عبر مستندات المخزون القائمة.

## الأمان وعزل الشركة
المسار الحالي يظل مسؤولًا عن `requireAuth` و`requirePermission('STOCK_RECEIVE')`، ويستخرج `tenantId` من `authContext`. لا يضيف هذا التغيير صلاحيات أو مسارات خادم جديدة.

## التحقق
`npx tsx scripts/verifyInvItemCreate.ts` — اختبار ثابت لوجود النموذج، والتحقق من الحقول، والاتصال بالمسار الحالي، والصلاحية ومفتاح idempotency، وسجل الحزمة.

## حدود الحزمة
لا تتضمن الحزمة تعديل بطاقة صنف موجودة، أو إنشاء رصيد افتتاحي، أو تغيير قواعد التكلفة أو المستودعات.
