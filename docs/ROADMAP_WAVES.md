# A.N ERP — خريطة الموجات السبع (بعد الدمج)

الإصدار المستهدف للتطوير التدريجي فوق 7.2.0. كل موجة = عدة حزم `AN-*.txt` صغيرة. لا قفز لموجة تالية قبل بوابة الاختبار.

| # | الموجة | هدف مختصر | حزم مقترحة (أسماء ملفات) | بوابة الانتقال |
|---|---|---|---|---|
| 0 | خط الأساس + Audit | صورة صادقة للكود والاختبارات والعيوب | `AN-BASELINE-MAP-1` (هذه) · لاحقًا DOC-SYNC عند الحاجة | السجل والخريطة يطابقان الشجرة؛ Open P1 = 0 أو موثّق |
| 1 | الأمان الكامل | صلاحيات خادم + دخول/جلسات + مستخدمون | `AN-SEC-AUTH-MATRIX` · `AN-SEC-SESSION-PASSWORD` · `AN-SEC-USER-ADMIN` | API يرفض بلا صلاحية؛ مسار كلمة السر/الجلسة مثبت باختبار |
| 2 | الشركة القانونية الصريحة | كيان شركة واضح + عضوية مستخدم | `AN-ORG-COMPANY-1` ✓ · `AN-ORG-MEMBERSHIP-1` ✓ | مستخدم لا يرى بيانات شركة غير مصرّح بها |
| 3 | مخزون الشركة الواحدة | UI/عمليات مكتملة داخل tenant | `AN-INV-UI-TABS` ✓ · `AN-INV-ITEM-CREATE` ✓ · `AN-INV-INTRANSIT-1` ✓ | صرف/استلام/تحويل/جرد + بطاقة صنف؛ اختبارات مخزون خضراء |
| 4 | المجموعة + صنف موحّد | Group + item master + إتاحة لكل شركة | `AN-ORG-GROUP-1` ✓ · لاحقًا `AN-MASTER-ITEM-GROUP-1` | كود صنف واحد للمجموعة؛ رصيد/تكلفة لكل شركة |
| 5 | تحويل بين شركات + محاسبة كيان | X-company stock + أثر محاسبي | `AN-STK-XCOMPANY-1` · `AN-ACC-ENTITY-CLOSE-1` | لا موافقة مسبقة؛ in-transit؛ دفاتر لا تختلط |
| 6 | تقارير/تجميع + إنتاج | KPI مجموعة ثم تجميع رسمي + تجريبي | `AN-RPT-GROUP-1` · `AN-CONSOL-1` · `AN-GATE-PROD-1` | أدلة اختبار + لا عيوب حرجة + نسخ احتياطي |

**مؤجّل صراحة:** إصلاح تلقائي بالAI، إعادة كتابة شاملة، WMS متقدم، موديولات جديدة قبل استقرار 0–2.
